Diagnostics retain all 1,358,559 rows. The 1,400,113 raw geometric constraints also include
relations excluded by prepass/other preparation; neither number equals the
active edge count. Existing Defect assignments neutralize 370,732 hard signs;
423,494 remain evaluated and all are satisfied. Hard surviving constraints do
not imply every input relation must remain active.

Initial state/message count 16,385,276 → 11,828,403; initial solve 349.0 s before versus
276.2 s corrected (20.9% less). No complete old 2048 wall time exists: that run was stopped.

candidate coverage/traces and graph construction change with the crop as noted
above, and both solves are capped.
