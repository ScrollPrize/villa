# C-007 — Explicit surface point dependencies ignore the vertex validity channel

Candidate priority: P2. Source-only review.

- `vc_object_store/src/geometry/Dependencies.hpp:146–194,207–252`: surface point dependencies check the canonical XYZ sentinel but never check the vertex's `valid` byte. The unchanged-array shortcut also ignores a changed validity channel.
- `vc_object_store/src/relationships/Edges.cpp:15–32` validates explicit endpoint dependencies through this helper when adding relationships. `vc_object_store/src/History.cpp:1035–1047` uses the dependency comparison for current graph applicability.
- `vc_object_store/src/geometry/Geometry.cpp:679–753` supports independent channel updates and assumes point dependencies can reuse the unchanged point reader. `vc_object_store/src/geometry/GeometryReader.cpp:611–621` and `vc_object_store/docs/editing.md:76–82` define valid vertices by both canonical XYZ and the optional validity byte. Explicit surface point relationships are exercised by `vc_object_store/tests/cpp/test_object_store_session.cpp:493`.

Trigger: Write a surface vertex with ordinary XYZ and `valid=0`, then add a relationship explicitly anchored to that grid point. The edge writer accepts a point that the selected surface geometry treats as a hole. Conversely, changing `valid` from nonzero to zero at a previously valid anchored point does not mark that edge affected unless the caller separately declared the entire `valid` channel as a dependency. Indexed/spatial surface readers already omit the vertex.

Expected: A grid-point dependency should exist and remain applicable only while that vertex is valid in the same selected geometry. This need not make an edit at an unrelated vertex affect all explicit point anchors. Declaring the entire validity channel can remain a distinct broader dependency.

Shared fix direction: Read the selected validity byte through the dependency geometry interface alongside its XYZ, share the typed vertex validity rule, and restrict the descriptor shortcut to cases where validity is also unchanged. Supply prospective channel bytes to that same interface when preflighting a channel edit. Regress edge creation at a masked point and mask edits at anchored and unanchored vertices, without making consumers add a manual channel dependency.
