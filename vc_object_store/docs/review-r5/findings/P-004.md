# P-004: reference evaluation relabels a saved solution's geometry as the current source

Priority: P2 candidate. Baseline `bea32d5d8`. Evidence: source trace, no runtime reproduction. Independent adjudication pending.

Locations: `vesuvius/src/vesuvius/neural_tracing/fiber_trace_3d/fiber_reference_comparison.py:325–342,649–693,705–717`; saved UV provenance in `fiber_uv_layout.py:121,241,1440,1487`.

Supported trigger: solve a UV layout and save its tensor cache/solution, then move a source fiber in the vcobj store without changing its UUID or arc length (for example a translation). Launch reference comparison on the saved run with a fresh projection cache. `run` reads the saved configuration and piece arrays but records a new `fibers_digest(cfg['fibers'])` from the current store, rather than checking the saved run's `input.signature.fibers`. `samples` then reads current polylines without a frozen `source_version`. It projects the moved curves onto the reference while computing fitted windings from the old saved layout. All existing identity checks on `source_id`, `start`, `end` and `family` still pass because those arrays are all from saved caches. A translation preserving arc lengths therefore changes comparison/accuracy results without any source mismatch error.

The newly built projection stamp names the current digest, so `load_metric_projection`'s later check against that same current store accepts the mixed-evidence projection. This is not merely the P-001 during-preparation race: here the original solve is complete and the source edit can finish before the evaluator starts, yet the evaluator deliberately recaptures a new signature instead of checking the saved one.

Expected/shared direction: compare the saved run's source identity against the selected geometry before interpreting old arc/state arrays, and guard the actual polyline read with the recorded source snapshot using shared `read_polylines(..., source_version=...)`. If retaining full source pins is not supported by an older run, reject a digest mismatch or explicitly regenerate/re-solve; do not certify old geometry state with a fresh digest. The same guard can serve preparation, projection, scoring and other saved-piece consumers. Regression: fixed saved run, equal-length source translation, fresh projection cache; reject instead of emitting metrics attributed to the old solve. No production or test edits in this review.
