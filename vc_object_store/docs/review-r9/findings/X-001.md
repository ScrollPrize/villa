# X-001 — Paired baseline certifies a live digest, not the source of the saved tensors

Confirmed by source at `8859fc945`. The missing-manifest failure from R8 is repaired, but `76924b4c8` makes a live-source input digest serve as a tensor provenance record. The documented producer `fiber_neighbor_expansion.run` hashes `parent_tensors` and separately calls `fibers_digest(settings['fibers'])` to populate `inputs.json` (`fiber_neighbor_expansion.py:127–145`). It never verifies the adjacent saved layout signature, which `fiber_uv_layout.prepare` produces with digest and source pin. Its catalog and polyline reads also do not receive a pin (148–161), and its final `tensors.npz` is an induced subgraph of that pre-existing parent, not a graph re-derived from the current polylines (256–266).

The changed `fiber_neighbor_pair.run` verifies that expansion digest against the live store, then writes it with the newly captured pin to `prepared/inputs.json` (35–56). `fiber_joint_gt_eval.run` accepts it and reads source geometry at that pin (79–107). A same-UUID fiber edit between parent tensor creation and a fresh expansion can preserve ID, support and usable arc ranges. Expansion can then combine old parent arc evidence with newer geometry; the paired and joint verifications accept the newer geometry because the purported source digest was taken after the edit. The paired free arm's comparison of exported curve coordinates with current geometry does not detect this if both were read after the edit.

The underlying unverified expansion input existed before `76924b4c8`; promoting its stamp to verified baseline evidence is new in that commit, whose parent instead rejected the absent prepared manifest. This is the immediate documented producer of the changed supported path, not an unrelated solver. Bind the saved parent to its original evidence and carry that pin into production and consumption of the expanded/prepared tensors. Test a publication before expansion (no race), a publication after pin capture, and unchanged source through the actual producer-to-joint path. Do not simply stamp old tensors with a current digest. No runtime test was executed.
