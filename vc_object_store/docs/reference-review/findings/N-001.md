# N-001 — Native pins flatten the selected reference

Status: candidate for independent adjudication; source-traced at `38c72d972`, not runtime-tested. Scope: schema 21, native/session/GUI, no model changes.

`include/vc_object_store/objects/ObjectStoreSession.hpp:38–46` defines `PinnedObject` as `ObjectIdentity object`, `generation`, and `version`; `reference()` reconstructs an `ObjectVersion`. `src/ObjectStoreSession.cpp:255–259` (`pinOf`) starts with a selected `ObjectRevision`, extracts its reference owner, then splits the remaining fields. This is an internal application record, not a serialization boundary. Attachment identity, active write generation, and geometry belong beside one retained `ObjectVersion`.

Producer/caller chain: `pinOf` → `SurfaceCatalog::open`, `StoreSurfaces`, `FiberCollectionController` selection, and `LineAnnotationController` load/save/`fiberPin` → `SurfaceStoreEdit`, segmentation/growth state, `ToolObjects::noteRead`/`writable`, `ObjectStoreSession::publishArtifacts`/`requireCurrent`. Checked publishing and current comparisons repeatedly call `pin.reference()`. `SurfaceStoreEdit::repin` already obtains the committed revision and goes through `pinOf`, so both initial and receipt-based pins need migration together. `LineAnnotationController.cpp:12488,12678` also constructs unsaved pins directly with version zero; preserve their unsaved identity explicitly rather than pretending these are valid published references. Display-only `pin.version` users include `SegmentationModule_Session.cpp`; fiber reads use `pin.object.objectUuid` plus `pin.reference()`.

Simplification: retain one complete reference in the stored pin, keep attachment/writeGeneration/geometry separately, and derive convenience identity/version accessors from it. Update all aggregate unsaved constructors and consumers in the same change. Do not merge attachment incarnation or active write generation with the publication reference: these are different guards.

Validation needed: current/inherited pins, metadata-only geometry reuse, receipt repinning, publication generation differing from active generation, retained exact reads after override/deletion, unsaved fiber publication. Existing native session/tool tests and VC3D surface/fiber/Spiral consumer tests are sibling boundaries; no runtime claim is made here.
