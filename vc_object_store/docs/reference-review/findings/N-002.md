# N-002 — Selected graph state is round-tripped through internal JSON-array strings

Status: candidate for independent adjudication; source-traced at `38c72d972`, not runtime-tested.

`src/internal/RecordResolver.hpp:70–105` explicitly calls its JSON-array reference representation “internal string transport”. `versionReferenceText` changes an `ObjectVersion` into `[store,generation,object,version]`; `parseVersionReference` changes it back. This is not confined to binary database IO or legacy external input.

Concrete entry chain: public `ObjectStore::relationshipsAt(Txn, vector<ObjectVersion>)` in `src/Versions.cpp:528–539` resolves every reference, discards the selected revision, builds a string-valued `RevisionSelection`, then calls the private overload. `src/History.cpp:947–1012` resolves those strings again, builds selected revisions, and subsequently invokes `versionReference(txn,*value)` and `resolveObjectVersion` again. `StoreReader`/`LocalStoreReader`, graph traversal (`src/relationships/Traversal.cpp`), selected fiber JSON (`src/formats/FiberJson.cpp`), geometry source metadata (`src/geometry/SourceMetadata.cpp`), hosted endpoints/client/session, and Python `relationships_at_versions` reach this chain.

Other producers/consumers of the same intermediate: `History.cpp` `head`, `publicationBase`, `metadata`, `members`, `relationship`, `currentObjectReference`, `resolveObjectRevision`, `recordedRelationship`; `Versions.cpp` receipts (separate N-004); transaction expected-history selection in `Versions.cpp`, `Transactions.cpp`, `Commands.cpp`; and the private `RevisionSelection` graph overload. `RelationshipRevision` simultaneously carries `aRevision/bRevision` string transport and `aReference/bReference`; recorded current-only endpoints are encoded as strings at `History.cpp:1080` then decoded during applicability checks.

Simplification: carry selected `ObjectRevision`/`ObjectVersion` through graph and dependency logic, and decode legacy archived revision identifiers once at a shared store boundary. A typed internal legacy/archive key may still be needed at the SQL adapter; it must not require serializing an already selected reference. Keep schema-21 16/56-byte binary columns unchanged. SQL binary encoding/decoding itself is legitimate and is not the finding. Archived revision UUIDs identify storage records, so not every string revision field should mechanically become an `ObjectVersion`.

Validation needed across both vector and archive/timestamp selection paths, read and publish/expectHistory counterparts: history on/off source and overlay, current/exact endpoints, inherited metadata edits/deletion, off-screen graph closure, packed/sharded scopes, and legacy archived membership. This is a consolidation finding, not a proven incorrect-result report.
