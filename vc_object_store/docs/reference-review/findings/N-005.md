# N-005 — Reference boundary codecs are duplicated instead of shared

Status: candidate for independent adjudication; source-traced at `38c72d972`, not runtime-tested. Related but distinct from internal transport N-002 and receipt array format N-004.

`src/Wire.cpp:16–25` owns an anonymous-namespace object reference encoder/decoder. `src/Commands.cpp` independently interprets restore `source` at lines 89 and 267; `src/DraftCheckpoints.cpp:33–42` owns another optional reference codec; `src/Selections.cpp:37–40,97–105` owns transform encoding/decoding. `python/ExtensionBindings.hpp:182–194` manually extracts `store/generation/object/version` and constructs `ObjectVersion`, while the ordinary binding helper `objectVersionsFromPy` in `python/objects.cpp:77–87` delegates to the native wire codec.

These are legitimate serialization/language boundaries, so serializing there is not itself a defect. The concrete simplification opportunity is repeated field interpretation instead of one shared native codec, contrary to the requested codec ownership. Their behavior is already different: Wire checks the exact key set but does not canonicalize UUIDs or check positive version; Commands canonicalizes UUIDs; selections canonicalize UUIDs and enforce positive versions; draft parsing directly assigns JSON fields; extension binding extracts through Python helpers. Some differences are enclosing-format policy, which must remain separate rather than being silently unified.

Sibling coverage: Wire reference helpers serve object-version requests, relationship endpoint references, and geometry-region run references; Commands serves restore and checked transaction JSON; drafts serve restart/recovery; selection codec serves v1/v2 persisted artifacts; extension binding template serves the binding classes registering extension methods. Normal Python refs/overlap/selection helpers use the shared request codec already. AgentBridgeHandlers_stores.cpp:321–324 serializes the complete export result at an external JSON response boundary; it is additional codec consolidation scope, not an internal flattening defect.

Simplification: expose native single-reference codecs, with explicit optional/legacy handling at the enclosing boundary, and migrate all these callers. Python only adapts Python containers. Preserve v1 selection fallback, compact v2 origin dictionaries, schema 21, and existing validation guarantees; no persistent identity redesign.

Validation needed: same valid/malformed full reference through restore, object reads, extension rows, draft restart, hosted region/history, export response and selection artifacts. Source review did not execute these cases; do not infer equivalent validation from one sibling passing.
