## Actual used path

They share the tuple converter but not a retained selected revision. `StoredSurface.__init__:140` again dismantles the selected grid record into `self.version = (generation,version,owner)`; tests consume that tuple and round-trip it into strings. Thus this is not merely a CLI formatter accidentally exposed as internal: the service itself creates strings and tuples between already structured selected identities and shared reads.

## Boundary versus internal transport

CLI `vcobj:UUID`, exact `vcobj:UUID@STORE/GENERATION/VERSION`, and older two-component suffixes are legitimate external inputs. JSON requests are also boundaries. The format need not disappear externally. Their codec and legacy current-owner resolution belong in shared native code, decoded once. Plain current UUID discovery remains valid. Compatibility does not require retaining the tuple protocol or reserializing JSON requests as CLI locators inside the process/job transport.

## Shared simplification

Provide/use shared native locator/request decoding; internally wrap `{reference: <standard reference>, type:surface}` plus application metadata, retain selected reference/revision in `StoredSurface`, and pass it unchanged to both grid and artifact APIs. At subprocess/config boundaries serialize the same dictionary, not a different locator representation. Decode legacy selectors in the store layer before exact operations. Migrate all sibling loaders and model paths together.

Estimated removable duplication: approximately 65–95 production lines across local formatting/parsing, tuple selection conversion and service extraction; a shared legacy codec costs additional native lines, so this is gross removal, not promised net savings. Preserve external older request/config readability; tests at `lasagna/tests/test_stored_surfaces.py:133` explicitly depend on tuple API and must migrate without dropping legacy input tests. Existing selected artifact-owner tests around 330 prove identity preservation on one path, not compliance with one representation.

Required future tests: JSON and CLI current/exact/legacy selectors through geometry and artifacts; inherited retained versions after override/deletion; both retention policies, hosted/local, packed/sharded; wrong owner/object, and sibling owners with equal counters. None were executed here.
