## Immediate integration/sibling traces

- `src/formats/GeometryInput.hpp` defines Prepared as `GeometrySource` and explicitly leaves database resolution/publication to ingestion. The per-kind decoders above obey that separation. `GeometryOutput.hpp` similarly takes immutable snapshots, not a database path/attachment to reinterpret.
- `src/geometry/GeometryIngest.cpp::prepareGeometrySource` supplies canonical ingest options/available identities and delegates per-kind decoding. The registered-source path resolves local source locators through `db.resolveStoragePath` instead of searching linked directories in a format helper. Packed-track store lookup is external-source decoding. For remote surfaces the registered object's UUID wins; remote `meta.json` is not allowed to replace the registered identity. Shared checked ingestion owns transaction/savepoint and cross-scope identity rules; this lane does not claim to re-audit every mutation in that separate implementation.
- `src/catalog/CatalogStore.cpp::fetchCatalogSurface` reads selected record/source metadata, delegates remote geometry loading, takes only decoded geometry, and supplies the complete loaded `record.reference()` to the shared fetch-write callback. A queued fetch does not substitute remote source metadata or silently override a concurrently edited local record.
- `src/geometry/GeometryExport.cpp::exportGeometry` uses the shared selectedObject/version/history graph APIs, `validateExportDestination`, immutable payload reads, source metadata conversion, cleaned staging and final atomic publication. Its calls to the GeometryOutput raw writers are not public APIs that bypass destination protection. Exact topology-bearing fiber/PCL exports use shared owner-timeline/graph capture, not local-only SQL or a history-off alternate path.
- `formats/FiberMetadata.hpp` explicitly shares native fiber metadata/branch conversion between selected JSON transport and native file export. This pass found no private copied exporter with conflicting owner/anchor policy among the assigned files.
