Frozen source baseline: `38c72d97222b3bc70a1a7477b6550c2a8eaec2aa`. New contract/review instructions are working-tree documents supplied for this audit; production source is unchanged. Schema 21 only. Review is source-only, not implementation, adjudication or runtime closure.

## Owning APIs and discovery

Native `ObjectVersion` owns identity; Python `object_reference(record)`, `receipt_object_reference(receipt,uuid)`, exact `objects_at_versions`, session exact grid/artifact readers and native boundary codecs own construction/validation. Python `locations.py` forwards standard reference lists to session APIs; `surfaces.py` accepts `reference` unchanged and adapts grid/array types. Its legacy version/generation arguments are genuine external convenience selectors, not a license for consumer-side owner reconstruction. `SurfaceGrid.record` retains selected record even though grid exposes version/generation display fields.

Discovery commands: `rg -l 'vc_object_store|vcobj|object_reference' --glob '*.py'` plus `rg -n 'ObjectVersion|object_reference|version_store|version_generation|generation|reference'` in discovered consumers; indirect callers traced via symbols below. Searches included tests and all repository top-level folders, not just names matching `spiral`. The actual Spiral folder is `spiral-fitting/`. Generic ML “reference”, model/checkpoint version, dataset version, service generation, geometry payload revision, and store freshness `{store,generation,commit_sequence}` are not object references; excluded unless used to reconstruct one.
