# Consumer screen and traced flows

Baseline: `153c9a10f`. 128 production candidates found through direct store symbols and shared surface/store adapter names. These paths were screened by store-related symbols/call sites, not all read line-by-line. Native core/bindings are Astra's separate lane. Tests provide evidence and are not counted as production coverage.

Detailed traces: native StoreSurfaces/ToolObjects load-edit-publish; QuadSurfaceStore/SurfaceGrid selected materialization and channel payloads; VC3D selected SurfaceCatalog and Spiral input adapters; Python selected facades, Spiral selection/pins/manifest validation; Lasagna surface/model/correction materialization and artifact provenance; Vesuvius surface adapters, fiber spline import and fiber catalog/geometry/block/evidence access. Legitimate shared delegation and application-specific XYZ/ZYX/densification/repair are not flagged solely for existing.

Known coverage limits: large GUI controllers and unrelated computational code were screened at their store entry points, not exhaustively re-proved. The inventory is reproducible candidate enumeration, not a completed-file checklist. Runtime results will identify exact scenarios tested; no blanket coverage claim follows from a passing older suite.
