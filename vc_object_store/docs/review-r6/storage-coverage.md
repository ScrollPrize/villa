## Dirty R5 delta, separately reopened

- S-001: shared hard-link rejection applies to ordinary writable opens, server ownership and both offline replacement modes; read-only dependencies remain distinct. No new source-confirmed ordinary alias bypass.
- S-002/S-003: registered ingest and catalog now share geometry-only remote staging; `AtomicFile` checks close before publication and removes its temporary name on failure. Existing optional remote-channel scope unchanged. Catalog refresh now patches metadata, and the existing-object request uses the full reference. The lazy catalog geometry writer remains a different optimistic publication boundary; its concurrency/owner matrix is not closed by the refresh test.
- S-004: collection copy now chooses the same overlay path for a single immutable root as for a partitioned root. Staged copy retains the immutable owner and reopens before publication; both plain and packed test cases appear in the delta, not executed here.
- S-005: report preflight/prepare improved, but the two publication points and copy ordering leave the cases in [S-002](findings/S-002.md) above.
- S-006: both candidate commit overloads call the implementation now owning a savepoint. The added catch-and-commit fixture is relevant; no runtime run here.
- S-007: server port is parsed into its final type and checks full consumption. This inspection does not establish every unrelated numeric CLI option is validated.
- S-008/S-009: project record and resource listing share one added-time comparison. Native session adds and Python resource upsert both use legacy resolution, but public tuple-derived UUID does not, producing [S-001](findings/S-001.md) above. No mixed-history/hosted timestamp fixture run here.
- S-010: hosted all-page object and edge filters are normalized before snapshots/catch-up. This does not prove the event replay under commits during paging.
- Adjacent durable draft checkpoint and anchor wire changes were inventoried for cross-lane handoff. Their recovery/checked-write and codec semantics are not closed by this physical lane.
