The ledger records specific traced paths and exclusions, not a complete inventory of native APIs or a claim that only these candidates exist. Exact source, retained revisions and local/reference comparisons above describe inspected code, not runtime results; a packed or hosted sibling being delegated to a shared API is not equivalent to exercising it.
