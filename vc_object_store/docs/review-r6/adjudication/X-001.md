# X-001 — accepted, P1, regression

`run(metrics_only=True)` directly enters `metric_report`; its nonempty solution loop loads only `cfg`, then evaluates `_verified_run_source(summary)`. There is no module/global `summary` binding, and other functions' locals cannot supply it. Any otherwise valid summary/tensor input reaches NameError before projection load. HEAD lacked this access. The added binding in `affine_vertical_setup` does not help.

Recommend P1 because the entire supported metrics-only solution workflow is broken deterministically, not merely an ownership edge case. No runtime execution; source proof is unambiguous. Test the top-level metrics-only caller, not only the projection helper.
