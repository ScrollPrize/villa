# C-002: Cross-object structural slices bypass retained target-ID allocation checks

Status: code-traced candidate; independent-model validation pending. Priority P2. Baseline `2b5d1e01fd26f27b3410d1b024c3f10a73533287`.

Location: `vc_object_store/src/geometry/StructuralGeometry.cpp:120–139,153–155`, `ObjectStore::editGeometrySequence`.

Trigger: target point collection/fiber-control sequence once allocated ID42 and later deleted it. Another object of the same kind has a different point with ID42. Insert a reference slice from that other object's revision into the target, using the supported cross-object splice API and correct expected versions.

New byte parts reject every previously allocated target ID at line139. Reference parts instead copy source IDs without checking their target allocation provenance; the final check only rejects IDs still live in the result. Deleted target ID42 can therefore identify an unrelated source point. This contradicts the retained-allocation guarantee: a historical reference may restore that target's actual old point, but a foreign object's same numeric ID is not that identity. Historical observations/annotations now have an ambiguous reused target-local key.

Cross-object copying is explicitly supported in `docs/editing.md` under structural sequence edits. Retained allocations are merged before the splice, so this is not missing bookkeeping; the reference branch bypasses its validation.

Shared fix direction: distinguish restoring a target's own historical identities from importing identities from another object. Reject/remap collisions with the target's retained allocations using the existing shared allocation API; retain same-object restoration and explicit IDs for new points. No extra per-object ID directory.

Evidence: code trace only. Regression needed in both history modes: remove target ID42, splice foreign ID42 and verify rejection or explicit safe remapping; same-target historical ID42 restoration must remain supported. Include target allocated IDs retained only in another referenced revision.
