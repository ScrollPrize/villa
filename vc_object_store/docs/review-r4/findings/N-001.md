# N-001: Restarting segmentation editing can discard unsaved correction points

Priority: P1. Baseline: `2b5d1e01fd26f27b3410d1b024c3f10a73533287`. Status: code-traced; no interactive GUI reproduction run.

## Location and trigger

`volume-cartographer/apps/VC3D/segmentation/SegmentationModule_Session.cpp:104` unconditionally calls `loadCorrections` whenever `beginEditingSession` succeeds. `loadCorrections` at lines 392–411 clears the old snapshot and replaces all anchored collections from storage. There is no save/pending-data guard before this reset.

The ordinary caller is `CWindow::onSegmentationEditingModeChanged` (`CWindow.cpp:5376`): every enable starts a session. `SegmentationModule::setEditingEnabled(false)` (`SegmentationModule.cpp:558–587`) does not save corrections. Edit correction anchors, then toggle editing off/on before their delayed save fires; alternatively let a save fail transiently, restore access and toggle off/on. The surface itself remains current, so the surface `requireCurrent` check does not protect the unsaved correction UI. The new session loads the old persisted points over the pending ones. `endEditingSession` also ignores the Boolean return from `saveCorrections` at Session.cpp:133, allowing the same restart after failed saves.

## Required behavior

Pending correction data must survive failed saves and session transitions. R3 guarded surface selection changes, but restarting editing on the same selected surface is a sibling path and bypasses that guard. This is not a request to silently overwrite an external update.

## Shared fix direction and regression

Use the same save-or-veto transition boundary for starting/restarting/ending editing as for selection changes, or preserve the existing correction snapshot while restarting the same selected editor. Do not create another correction resolver. Test a correction edit followed immediately by editing off/on, and a rejected correction save followed by restart; pending points and the original optimistic baseline must remain until a successful save or explicit discard.
