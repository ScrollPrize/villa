# Task log: exact float-cache fiberlet replay

## Finding

- The corridor-filtered eager and cached paths both produced 2,617 anchors and
  26,686 accepted fiberlets on the canonical 5,000-base-voxel Paris4 interval.
- Their replay outputs diverged: eager selected 342 route points with total
  loss 91.7058, while cached selected 346 points with total loss 131.6672.
- The cache prefix stores only total edge cost and entry/exit lattice values.
  Cached replay reconstructs endpoint steps, puts total edge loss in the
  alignment bucket, and independently resamples prediction/normals for joins.
  Eager replay retains exact route steps, all cost components, and the canonical
  endpoint interpolation samples generated by `traceFiberletPaths`.
- Full cached route reconstruction also retained interior points that DP output
  suppresses when adjacent positions are equal within the path epsilon.
- A successful cached replay is not evidence of equivalence. Float-cache replay
  must be byte-identical to eager replay for the same extracted graph.

## Deviations

- None currently.

## Independent plan review

- Reuse the eager float path-length calculation; the existing on-demand helper
  accumulated in double and could change beam density ordering by one bit.
- Persist base-space endpoint steps computed by scale-then-subtract, matching
  eager arithmetic. Prediction-space subtraction followed by scaling is not
  generally bit-identical, especially at non-power-of-two scales.
- Persist `presenceValid`, reject noncanonical flags/invalid floats strictly,
  and keep one logical cost source of truth per storage profile.
- Canonicalize diagnostic indices from stable IDs in both adapters before using
  replay JSON equality as the integration gate.
- Test duplicate endpoint/interior points, invalid scoring and normals, strict
  join-angle equality, cold/warm cache replay, schema rejection, and graph
  fields that are not represented in replay JSON.

## Implementation

- Replaced the unpublished payload envelope with strict version 2 and changed
  the cache algorithm identity. No version-1 decoder or repair path remains.
- Float anchor chunks now store canonical interpolated prediction direction,
  presence, both validity flags, normal, and normal validity. Fiberlet
  generation asserts that its independently materialized endpoint samples are
  exactly equal to those anchor records.
- Float prefix chunks now store all five path-cost components, the eager float
  path length, and exact base-space endpoint steps. Cached arcs consume these
  values directly, and cached transitions use the shared stored anchor sample.
- Committed cached route reconstruction now uses the same adjacent-point
  epsilon suppression as DP finalization. Replay diagnostics now use stable
  encounter IDs in both eager and cached adapters.
