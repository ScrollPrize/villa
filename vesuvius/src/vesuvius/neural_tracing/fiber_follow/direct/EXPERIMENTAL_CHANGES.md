# Experimental changes

Status: implemented and validated; background training `direct_ct_spatial_run1` is running (PID 1348604).

Started: 2026-09-26. Baseline: `output/direct_ct_judge_run2`.

## Objective

Produce long, connected traces of the original fiber while avoiding switches to
neighboring fibers. Improving local coordinate accuracy is useful, but success
depends on preserving identity through contacts and ambiguous regions.

The next experiment should learn more directly from CT and expose enough detailed
spatial context to follow a fiber through those regions. The two agreed input
changes are:

1. Remove fiber presence from the model inputs.
2. Increase the fine CT crop size while retaining native CT sampling resolution.

The next experiment combines these inputs with a history-conditioned spatial
predictor, small immutable seed context, and a bounded set of complete candidate
passages within one enlarged crop. Score these passages before committing a short
prefix, then discard the remaining predictions and reobserve. Train on examples
spanning complete contacts. This is a combined system experiment; a sequence of
full-training ablations is not a prerequisite.

The direction is principled, but the baseline does not establish which mechanism
limits tracing. Keep the first system small enough to diagnose. Persistent search
branches, learned memory updates, separate direction/connectivity/uncertainty
heads, and recurrent training unrolls are deferred. The representation, scoring, supervision, and commitment contracts are now
implemented as specified in the review decisions and implementation record below.

## Review decisions for implementation

All points between the first and last human control point have the same validated
quality, as confirmed by the user. Interpolation/optimizer provenance does not
reduce their validity. Existing validated paths supply positive passage targets
directly. Missing coverage outside these spans remains censored. Contact indexing
uses these validated paths; no extra human review is required solely because a
path was generated by the native tracer.

Keep the spatial heatmap design, with one shared CT encoding and bounded coherent
path extraction. Correct-continuation recall before/after pruning is a first-class
metric: a scorer cannot recover a missing proposal. Retain route diversity rather
than only small variations of the best endpoint. Bootstrap scorer supervision
with valid annotated passages, perturbed passages, and matched wrong connections;
refresh model-generated candidates each update. These training candidates never
enter inference or become committed history.

Use one horizon-conditioned candidate scorer trained with masked binary
cross-entropy. Its logit supplies both ranking and acceptance. Defer a separate
ranking loss; the existing beam quality-softmax loss orders even all-invalid pools
and must not be copied unchanged. Evaluate the same scorer over short prefixes and
the complete passage. Distant uncertainty alone must not veto a supported short
advance. At a fork affecting the committed prefix, require a resolved choice;
agreement between candidates alone does not establish validity. This scorer is
the sole learned stopping authority, replacing both old confidence and judge gates.

Represent the current frontier explicitly in crop coordinates. Fixed-crop prompt
swaps must change the frontier and history consistently while retaining the same
CT, crop origin, and frame. Seed context contains only a supplied seed/heading,
with its original CT view and provenance; older replay with no recorded seed
uses an explicit missing-seed mask. Do not relabel a generated history point as a
trusted seed.

Extend the existing collector's pre-failure windows (already 48 trace voxels),
replay refresh, checkpointing, and diagnostics. Preserve the old architecture
and its checkpoints. Use a separate architecture identity for this experiment.
Before launch, run regression tests, contact/geometry audits, small-set fitting,
prompt-swap checks, and a full-input CUDA memory/throughput preflight. Record the
chosen crop, candidate limits, training mixture, policy, and launch command below.
No series of full-training ablations is required. Compare calibrated checkpoint
selection on both systems; step 17,000 is not automatically the best baseline.

## Remove fiber presence from model inputs

Use CT as the image evidence for both fine and coarse inputs. Continue supplying
the seed and observed tracing history as conditioning information.

Presence is already a derived fiber signal. For a model learning centerline/tube
evidence, it creates a plausible shortcut: the model could reproduce or refine
that signal without learning enough from CT to resolve the cases where the
presence prediction is ambiguous or wrong. Actual reliance on presence has not
yet been measured; this is a design motivation, not an established diagnosis.

Removing it tests whether direct CT learning improves tracing and removes that
input's crop reads, resampling, and transfer. It may also remove useful evidence;
neither an accuracy gain nor harmful reliance on presence has been established.

Implementation should remove the channel and its loading path, rather than keep
a permanently zero channel. Audit the volume reader as well: it currently opens
presence and uses its shape for trace-grid bounds. A CT-only path must derive
equivalent bounds from CT metadata and explicit coordinate scales. Any use of
presence for seed selection should be documented separately from model input;
fixed evaluation seeds should stay comparable across experiments.

The eventual output should describe the continuation of the **seeded fiber**.
Generic fiber presence alone would still leave neighboring fibers indistinguishable.
History conditioning and the output supervision must express this distinction.

## Choose crop, prediction, and commitment horizons together

Increase its physical field of view by increasing the number of samples at the
existing 0.5-trace-voxel spacing. The exact dimensions and behind/ahead allocation
are still open.

Prioritize more detailed context along the tracing direction, both before and
after a contact. Include enough lateral context to show competing nearby fibers.
The goal is to expose continuity through the ambiguous region. The current fine
crop sees 23.5 voxels ahead, predicts 16 forward planes at one-voxel spacing, and
normally commits four. Extra input alone does not ensure that candidates extend
far enough to resolve a contact.

Measure approach-to-separation distance, lateral spread, and required incoming
context on the training contact collection. Measure lateral excursion and forward
monotonicity relative to imperfect model-generated or perturbed approach frames
as well as annotation-derived headings. A crop that fits an ideal heading may
fail during tracing. Use these measurements and the resource budget to choose
crop extent, candidate horizon, and short commit length together. Candidates
should include stable continuation beyond separation when the available evidence
permits it. Stop when the available lookahead cannot resolve a choice; a larger
crop cannot resolve a pairing that the image evidence does not distinguish.

Keep coarse context as a complementary source of longer-range information. The
current long backward view is coarser; a larger fine crop would preserve more
detail over the region where identity must be resolved.

A larger crop must also be usable by the model. Give the spatial decoder access
to detailed encoder features through skip connections or equivalent feature
sampling. Native CT input spacing does not require every feature map and output
head to operate at native resolution. Choose output resolution for localization
needs and measure whether it preserves distinct candidate exits.

Accessing a genuinely higher-resolution CT source is a separate possible
experiment. It is not required for this field-of-view expansion.

## Predict conditioned centerline likelihoods

Replace the single coordinate output with target-centerline heatmaps on forward
planes, conditioned on the seed and observed history. Preserve distinct spatial
peaks instead of immediately reducing them to a mean coordinate, which can lie
between fibers. Extract coherent candidate curves from those peaks, then refine
coordinates if needed.

The current model produces one lateral coordinate pair at each of 16 forward
planes, followed by bounded local corrections. Its pooled fine-image tokens have
an effective spacing of four trace voxels. Detailed features remain available
locally, but there is no detailed spatial decoder conditioned on the target.
Start by adapting the existing encoders and history-conditioned transformer
queries: sample or modestly decode fine and deep features onto the output planes,
then use each plane query to score lateral locations. This provides a small
spatial head without requiring a new full-resolution 3D decoder. Architecture
reuse does not require reusing trained weights from the two-channel baseline.

Verify that conditioning affects the spatial predictions. Injecting prompts into
every shallow stage is not itself a requirement; the required behavior is that
the same CT evidence produces different continuations for different valid fiber
prompts.

Voxel or plane likelihoods do not define a joint distribution over complete
paths. A two-branch heatmap can permit a curve that changes identity between
planes; a tube map can merge touching fibers. Geometric continuity constraints
and a history-conditioned score for each complete passage must express the
incoming-to-outgoing pairing. Local direction or neighbor affinities alone do
not guarantee this behavior. Defer separate direction, connectivity, and spatial
uncertainty heads until their added role is demonstrated. Heatmap sharpness is
not automatically calibrated confidence that a continuation is correct.

Start with centerline supervision from existing annotations. For a unique, known,
in-crop target crossing, train a categorical distribution over lateral locations
on that plane, using an annotation-tolerance-aware target. This does not require
annotating every neighboring fiber: other locations are alternatives to the known
target crossing, not labels that those voxels contain no fiber. Mask censored,
out-of-crop, and unresolved target crossings. A normalized plane distribution
always places mass somewhere; it cannot establish that any continuation is valid.
That decision belongs to the candidate acceptance scorer.

If selected positive/negative-site supervision is later added, define its masks
separately; missing annotations must not silently become generic background
labels. A dilated centerline is a training representation, not an accurate
physical fiber boundary.

Forward-plane prediction assumes local monotonicity along the tracing direction,
as the current representation does. Audit this assumption over the enlarged
horizon. The current `plane_targets` selects the first forward crossing and does
not verify uniqueness. Increasing its horizon alone will not implement the
required masking: detect multiple crossings and invalid passage geometry
explicitly. If folds or multiple crossings are common, shorten/reorient the local
window or justify a more general 3D representation from those failures. Record
how often these cases exclude complete candidate passages from training.

## Keep conditioning and state simple

Use three kinds of context in the first system:

- Small immutable seed context, retaining a spatial representation if useful.
- Recent committed observed history, with its geometry and sampled CT evidence.
- Candidate geometry and sampled features local to the current decision; these
  are hypotheses, not additional committed history, and are discarded afterward.

Distinguish the supplied seed point/heading or externally supplied prefix from
subsequent model-generated observations. Do not silently promote the first few
predicted positions into trusted seed context. Record the origin of each retained
seed observation and include early tracing errors in validation.

Committed history is an inference-time estimate and can be wrong. Train with
model-generated and perturbed histories as well as clean ones. A distant seed's
appearance or neighbor arrangement may change along a fiber; persistent context
cannot create identity evidence that the CT does not contain.

Defer a learned bank of older spatial memories and its admission/eviction rules.
Using sustained model confidence to certify memory is circular when confident
switches are the failure of interest. Revisit learned updates only after showing
that correct choices require evidence beyond seed context and recent history,
and specify training for erroneous updates, coordinate alignment, and rollback.

Explicitly train conditioning using the same CT crop with different fiber
prompts: prompting annotated fiber A should produce A's continuation, while
prompting neighboring B should produce B's. This tests whether conditioning
controls identity rather than merely supplying a heading. Hold the CT, crop
origin, and coordinate frame fixed, and express both valid prompts in that frame.
Annotation identities are training labels, not model inputs. Treat this prompt-swap
check as required validation. Contact examples must retain a distinguishing
prompt; do not blindly carry over history dropout when it would erase the
information needed to determine the requested identity. Keep startup/no-history
examples as a separate case.

## Score complete passages within one crop before committing

Use one fixed physical lookahead window that covers contact separation where
possible. The first inference policy is:

1. Encode the enlarged crop once and predict conditioned plane heatmaps.
2. Extract a small, bounded set of geometrically coherent complete passages in
   the same crop frame. A bounded search through plane peaks with continuity
   constraints is sufficient initially; it does not persist across tracing calls.
3. Score each passage against the same seed context and committed incoming
   history, with candidate geometry/features explicitly identified as hypotheses.
4. When the short prefix is supported and its immediate branch choice is resolved,
   commit only that prefix. Complete-passage scores guide the choice, but distant
   uncertainty does not by itself veto supported progress before a contact.
5. Discard all remaining candidate predictions and recompute from the new
   committed position. Stop if no continuation is supported or the choice remains
   unresolved within the available lookahead.

CT is a fixed volume. If the crop already shows both exits of a contact, its
downstream evidence can influence the choice immediately. Advancing a speculative
path does not add information already available in that crop. This first policy
therefore needs no persistent branches, tentative history streams, or rollback.

Specify candidate count, extraction/pruning, accepted-choice criteria, and commit
length before implementation. A highest score alone does not establish that a
choice is resolved. Calibrate acceptance and any ambiguity rule under the actual
selection policy. Require full-passage support when credible alternative routes disagree within
the proposed prefix. Before that disagreement, independently supported prefixes
can advance even when the distant connection is uncertain. Candidate agreement alone is not evidence of correctness, and averaging
different candidate curves can produce an invalid path between fibers.

Candidate diversity must preserve different exits or connection patterns, not
only small perturbations of one curve. Track whether the correct continuation
survives proposal generation and pruning. Enforce geometric continuity while
allowing distinct exits; smoothness alone cannot prevent a smooth identity switch.
The scorer must retain the original prompt throughout passage evaluation. It
must not treat a candidate's own continuation as trusted history that redefines
which fiber it is supposed to follow.

Train absolute acceptance using masked binary cross-entropy on one candidate logit
initially, and rank candidates by that logit. Defer an additional ranking loss.
Ranking alone always selects a winner, even when every candidate is
wrong. The absolute target means connected continuation of the seeded fiber over
the evaluated passage. Define these labels before implementing the scorer:

- Known valid: the passage preserves the annotated incoming-to-outgoing pairing
  throughout its evaluated extent, within the defined localization tolerance.
- Known invalid: a wrong connection, identity switch, or other defined geometric
  failure is established anywhere along the passage. A switch followed by a return
  to the target is still invalid.
- Unknown: available annotation cannot establish either outcome; mask this
  candidate from the scorer loss.

Distance tolerance alone does not establish identity. A wrong neighbor can stay
within the current departure threshold for a substantial distance. Supervision
must use resolved contact pairings and passage geometry, not simply reuse the
judge's distance-based departure labels. Ground-truth branch identities are only
used to construct targets, never supplied as model inputs.

Include sets where every candidate is known invalid. Do not confuse these with
sets having no known valid candidate but one or more unknown candidates. Unknown
endings and unresolved contacts must not teach rejection. Wholly unknown sets
contribute no scorer loss. Rank known valid passages above known
invalid ones; any ordering within those groups needs an explicit quality target.
All-known-invalid sets still teach binary rejection without requiring a winner.

Initially compare candidates over the same forward-plane horizon in the common
physical frame; their arclengths may differ. Define tolerance, annotation censoring,
and out-of-crop handling explicitly. Requiring full-passage support can sacrifice
safe short progress when only the distant continuation is uncertain; measure
that premature-stop cost. Do not sum intact-prefix probabilities from the current
judge as if they were independent step scores; that repeatedly counts overlapping
evidence. Use a learned complete-passage score, and treat heatmap path scores as
proposal heuristics rather than calibrated passage probabilities.

The current judge can stop or truncate a single proposed curve but cannot select
an alternative. Rework its useful evidence into a history-conditioned candidate
scorer that acts before commitment, with stopping as a remaining outcome. The
existing `beam/` implementation provides search/scoring concepts to reuse where
appropriate; its cone proposals and CT resolution are not requirements for this
new spatial predictor. Reuse its shared-encoding and binary-supervision concepts where appropriate,
with labels for continuation of the original fiber. The first run uses BCE only. Reusing judge
inputs or encoders does not establish that its current weights can rank branches.

Keep committed observations append-only. Sample candidate features from the
shared crop into temporary tensors; do not append candidates to the current
`SliceStream`, which rejects rewritten paths. Candidate scoring and disposal must
leave committed observations, frames, and caches unchanged.

Defer persistent branching and revisable tails until measured failures show that
important contacts exceed the affordable crop or require successive reorientation
to inspect. Revisit them only with evidence that extending lookahead resolves
those failures. That follow-up would require bounded branch histories, frame and
cache ownership, pruning, commitment, and rollback rules. It is not part of the
first training or inference budget.

## Train on identity decisions at contacts

Build a spatial index of annotated contacts and a reusable collection of contact
episodes. Each episode should contain incoming context, the correct continuation,
plausible neighboring continuations, and sufficient downstream extent to tell
them apart. Use both prompt directions where annotation supports them. Exclude
duplicate annotations from confirmed competing identities and mask unresolved
contacts.

The current synthetic contact generator samples random fiber pairs. Across logged
batches at steps 14,000--17,000, six extras are requested and 5.03 fall back on
average, leaving about one successful extra sequence. Departed replay supplies
12 extra sequences per logged batch in that interval. Indexing actual contacts
should supply deliberate decision examples; a general shortage of negatives is
not the established diagnosis.

Mine actual rollouts before their first failure, retaining the approach to the
contact and competing branches. Current confirmed departed states lose geometry
supervision and mainly teach rejection. Earlier decision states can teach the
continuation that prevents departure. Preserve existing replay as a source of
realistic errors, but organize these new episodes by the identity decision as
well as drift magnitude.

Prioritize additional annotation at ambiguous contacts, including neighboring
identities and the correct incoming-to-outgoing pairing. More ordinary straight
segments may be less informative than a smaller set of resolved contacts. Human
review should distinguish truly unresolved image evidence from model failures.
Neighbor annotations support contact ranking and identity evaluation; they are
not a prerequisite for every uniquely known target-plane training example.

Keep ordinary continuations in the training mixture. Oversampling difficult
contacts changes the decision distribution and can distort stopping calibration;
record the mixture and calibrate on representative held-out traces. Split contact
episodes before augmentation, keeping both prompt directions and overlapping
views of the same contact together.

## Train complete passages without recurrent unrolling first

Use contact episodes as supervised examples, not initially as recurrent
computation graphs. From a model-generated or perturbed approach state, generate
candidate passages, label their connected continuation of the original fiber,
and train spatial prediction and absolute candidate validity; rank by validity logits. A centered
path on the wrong neighbor must lose to a path that preserves the target identity.
Define candidate-quality targets and unknown-label masks before implementation.

Retain DAgger/replay to expose model-generated histories and refresh candidate
sets as the policy changes. Gradients need not pass through discrete extraction
or search: spatial supervision trains proposals and candidate supervision trains
selection. Record how each head receives its learning signal.

Defer differentiable tracing unrolls and learned memory updates until a recurrent
state mechanism or measured distribution gap justifies them. Also defer the
two-anchor reconstruction task: its far endpoint is unavailable in open-ended
deployment, and it is not needed for the first contact-selection experiment.

## Combined next experiment

Introduce the following as one coherent experimental system:

1. CT-only fine/coarse inputs with an enlarged fine field of view.
2. A modest forward-plane heatmap head adapting existing encoders and
   history-conditioned queries, with access to detailed features.
3. A bounded set of coherent candidate passages within one crop, with one
   history-conditioned scorer trained with masked BCE at short and full extents,
   supplying both ranking and absolute acceptance.
4. Small immutable seed context, recent committed history, and short-prefix
   commitment followed by discarding predictions and recomputing.
5. Indexed contacts, pre-departure replay, and complete-passage training examples,
   mixed with ordinary continuations.

Defer persistent search branches and revisable tails, the learned spatial memory
bank and promotion policy, separate direction/connectivity/uncertainty heads,
recurrent training unrolls, and the two-anchor task.

Keep the original run as a baseline. Preserve diagnostic controls such as one
candidate versus several and disabling seed context. Inference-time removal of
conditioning can shift the input distribution, so it diagnoses reliance rather
than replacing a matched training ablation. Smaller training controls can follow;
none of these changes has yet demonstrated an accuracy gain on these fibers.
The combined experiment can establish whether the system improves tracing, but
cannot attribute an improvement to an individual component.

## Resource tradeoff

Removing presence does not fund a proportional increase in crop volume. It
halves the input channels and reduces first-convolution work, but leaves later
feature-map sizes and most model computation unchanged. In the current two
encoders, it removes only 1,296 weights.

Increasing crop volume expands intermediate activations, convolution work, CT
reads, and potentially attention cost. Measure peak training memory and
end-to-end samples per second before choosing final dimensions. Record crop
shape, physical extent, batch size, and precision with each measurement.

Include the plane head, seed features, candidate extraction/scoring, and temporary
candidate tensors in the resource budget. Share CT encoding across candidates in
the common crop frame. Measure inference latency and peak memory on ambiguous
contacts as well as ordinary continuations; average training throughput alone
does not capture the cost of search. Persistent branch state, learned memory
banks, and unrolling are not part of the first-run budget.

Choose the larger crop for the additional evidence it provides, with an explicit
resource budget; do not assume a twofold input-channel reduction permits a
twofold crop-volume increase at unchanged cost.

## Validation and remaining decisions

Before the expensive run, perform bounded checks that make the combined system
reviewable:

- Fit a small set of resolved contacts in both supported traversal directions;
  verify prompt swapping with the CT, crop origin, and coordinate frame fixed.
- Audit annotation coverage and the unique-forward-crossing assumption over the
  chosen lookahead window, including imperfect approach frames. Check explicit
  multiple-crossing detection and masking at unresolved contacts and endings.
- Measure correct-continuation recall before and after candidate pruning, then
  selection accuracy when a valid candidate exists. Check distinct exits and
  pairings, not only small coordinate variations.
- Check rejection for all-known-invalid candidate sets and loss masking for
  mixed/wholly unknown sets. Include smooth switches and switch-then-return paths.
- Verify that seed observations retain their provenance and that hypothetical
  candidates cannot redefine the committed prompt.
- Exercise candidate scoring/disposal and short-prefix commitment without
  speculative changes to committed observations, frames, or caches.
- Measure full-input training memory/throughput and contact-search latency.

An optional follow-up control is CT-only input at the original crop size versus
the larger crop within the same new architecture. This can isolate the value of
field of view without delaying the combined experiment.

Evaluate correct connected length, identity switches, premature stops, and
performance at difficult contacts, alongside localization error and throughput.
Use fixed held-out seeds and retain the original baseline for comparison. Lower
training loss alone does not establish better tracing.

Calibrate baseline and new-model thresholds on the calibration split and compare
connected correct length at comparable wrong-length rates. Longer traces must
not count as a gain merely by continuing incorrectly. Calibrate the new scorer
after candidate selection with the deployed candidate count, extraction/pruning,
and commitment policy; isolated candidate calibration is insufficient. Add a
held-out contact set and longer rollouts beyond the current 400-voxel monitor cap.
Report contact traversal accuracy, premature stops, confirmed identity switches,
and geometric departures separately. Use paired fiber/contact uncertainty
estimates; augmented views or two traversal directions are not independent
experimental units.
Measure correct-continuation recall among candidates before and after pruning,
then selection accuracy when a correct candidate exists. This separates failures
of proposal generation from failures of scoring or memory.

Keep annotation censoring and coordinate scales explicit. Expanded crops,
episode paths, candidate paths, and seed/history evidence footprints must all
respect the held-out region; audit the existing exclusions when extending these
inputs.

## Implemented experiment and validation record

The new architecture is `direct_spatial_passages_v1`; legacy `direct_curve_v1`
checkpoints remain loadable. `--spatial` selects the new model, observation builder,
loss, and contact mixture through the existing trainer. Training starts from scratch;
small-set preflight weights are never used to initialize the production run.

| Contract | Implemented value |
| --- | --- |
| Fine CT | 160 × 96 × 96, spacing 0.5; 24 behind, 55.5 ahead, ±23.75 lateral |
| Coarse CT | Existing 88 × 32 × 32, spacing 2.0 |
| Output | 48 forward planes, spacing 1; 46 × 46 lateral grid over ±22.75 |
| Spatial target | Normalized Gaussian categorical target, sigma 0.65 trace voxels |
| Proposals | Up to 12 plane maxima plus a central fallback; two routes per endpoint; at most 26 final routes before pruning to eight |
| Geometry | First connection ≤6 voxels; subsequent lateral displacement ≤2.5 per plane; small displacement/curvature proposal costs |
| Diversity | Remove candidates within one voxel of a retained route everywhere; preserve routes with different intermediate passages even if exits coincide |
| Scorer | Shared path-feature network, one prefix-validity logit at each extent; masked BCE, weight 0.5; no extra ranking loss |
| Labels | Localization tolerance 1.5 plus known-neighbor identity checks; a neighbor closer by 0.25, within tolerance, and separated from the target by >0.5 establishes a wrong connection |
| Commitment | Up to four points; full-passage ranking uses the minimum prefix logit; no averaging or persistent candidate state |
| Ambiguity | Rival full score within one logit, prefix probability ≥0.5, and prefix separation >1 voxel requires full-passage confidence at the externally chosen acceptance threshold |
| Seed | Supplied seed/heading and immutable 16³ native CT crop; eight spatial tokens using the shared local encoder; absent-provenance mask for legacy replay |
| Contacts | 35% requested contact samples in paired prompts; remainder retains the existing fresh/fixed/recent sampler and fallbacks |
| Replay | Existing fixed bank and online DAgger; archive first point/frame preserves the original supplied seed |
| Monitoring | Original 400-voxel monitor plus fixed monitor-only contacts; additional 1,200-voxel monitor rollouts every 5,000 updates |

The volume reader derives CT-only trace bounds from CT metadata and coordinate
scales without opening presence. Presence remains an explicit, separate dependency
of seed selection for DAgger; frozen evaluation seeds are unchanged. No annotation
identity, target, or competing-fiber label enters the model conditioning. Four
annotation-derived teacher candidates bootstrap the scorer during training only;
the predictor and deployed search never receive them.

The deterministic proximity index contains 1,498 training contact episodes.
Its coarse approach/contact/separation estimate fits a 48-voxel horizon for 94.6%
of episodes. This estimate is not a guarantee of representability in an imperfect
frame. The unfiltered frame audit is retained in
`output/direct_spatial_preflight/report_unfiltered_frames.json`.

Complete-contact training requires both prompted passages to have unique, annotated,
in-crop crossings and supported step geometry. In the final bounded sampling audit,
128 paired examples were admitted from 1,769 trials: 96 were excluded by horizon,
1,524 by geometry/shared-frame suitability, and eight by held-out footprints; the
remaining rejected trials were near annotation boundaries. Admitted examples are
complete by construction. These exclusions are a material limitation of this
representation, not evidence that the excluded annotations are unreliable. Ordinary
and replay examples retain partial-supervision masks rather than being discarded.

The real-CT small-set check fitted two prompt pairs across both traversal directions
for 200 updates. Mean heatmap-peak error reached 0.384 trace voxels. Own-prompt errors
were 0.35–0.40, versus 6.54–6.66 against the swapped prompt targets. All four correct
passages survived pruning and were selected. This is a wiring/learnability check;
it does not establish generalization. Synthetic regression checks additionally
exercise all-invalid rejection targets, unknown masking, switch-then-return labels,
immutable seeds, frontier conditioning, and supported progress before distant forks.

On the RTX 5090, the full eight-sample microbatch used 12.72 GB peak allocated CUDA
memory with bf16 autocast. Five warmed updates averaged 0.183 seconds (43.7 samples/s),
including proposal search, scorer teaching candidates, backward, and optimizer work.
A real eight-sample CT read took 0.865 seconds separately; the training log will
report end-to-end throughput with loaders and diagnostics. A four-prompt inference
batch averaged 0.0436 seconds with a 0.0443-second p95 over five warmed calls.
The resource report and exact configurations are in

## Architectural references

- [Flood-Filling Networks](https://research.google/pubs/flood-filling-networks/):
  recurrent 3D prediction of individual segments from raw imagery motivates the
  target-conditioned spatial continuation direction, without requiring a full
  volumetric segmentation head for the first experiment.
- [SAM 2](https://arxiv.org/abs/2408.00714): streaming memory for prompted video
  segmentation motivates retaining target context. This is an architectural
  analogy, not evidence that distant fiber cross-sections retain identifying
  appearance or that a learned memory bank is needed here.

These references support design ideas; neither establishes performance for this
dataset or the proposed combination.
